# Zirasport

## Español

Zirasport es un portal deportivo digital desarrollado para centralizar noticias, análisis y contenido audiovisual en una experiencia editorial moderna. El proyecto combina una portada de alto impacto con páginas independientes por sección y artículos completos con imágenes, videos y contenido enriquecido.

### Qué ofrece

- Portada general con noticias destacadas y accesos directos a las coberturas.
- Páginas independientes para cada sección deportiva.
- Artículos con título, bajada, imágenes, videos, pies de foto y contenido estructurado.
- Administración de noticias, categorías y recursos multimedia.
- Modo de edición para usuarios con permisos, con edición controlada de textos e imágenes.
- Sistema de roles y permisos para usuarios, editores, administradores y superadministradores.
- Invitación y gestión de administradores desde el panel privado.
- Diseño responsive para escritorio, tablet y dispositivos móviles.
- Identidad visual propia con header, footer, navegación y componentes editoriales de Zirasport.

### Secciones del portal

- Fútbol masculino
- Fútbol femenino
- Fórmula 1
- Selección Argentina

### Tecnologías

- Next.js 16 con App Router y React Server Components.
- TypeScript con tipado estricto.
- Tailwind CSS para el sistema visual responsive.
- PostgreSQL como base de datos.
- Prisma ORM para el acceso y modelado de datos.
- NextAuth para autenticación y sesiones.
- Cloudinary para almacenamiento y gestión de imágenes y videos.
- Arquitectura basada en Server Actions, rutas protegidas y renderizado optimizado para SEO.

### Modelo de datos y administración

La plataforma organiza usuarios, perfiles administrativos, permisos, invitaciones, categorías, publicaciones, layouts, contenido del sitio, multimedia y registros de auditoría. Esto permite ampliar el portal sin depender de una estructura rígida y mantener un control claro sobre quién puede publicar o modificar cada recurso.

### Destinatario del proyecto

Zirasport es un desarrollo freelance creado para una marca deportiva, un medio digital o una organización que necesita publicar contenido con identidad propia y administrar su portal desde un panel privado. El sistema está pensado para equipos editoriales pequeños y medianos que requieren autonomía para crear noticias, gestionar contenido multimedia y mantener actualizadas sus secciones sin depender de cambios constantes en el código.

### Objetivo

Construir una plataforma deportiva escalable, rápida y fácil de administrar, con una presentación editorial profesional y una base sólida para incorporar nuevas categorías, autores, formatos y funcionalidades.

## English

Zirasport is a digital sports news platform built to centralize news, analysis and audiovisual content in a modern editorial experience. The project combines a high-impact homepage with independent section pages and full articles containing images, videos and structured content.

### Main capabilities

- General homepage with featured stories and direct access to sports coverage.
- Independent pages for each sports section.
- Articles with headlines, summaries, images, videos, captions and structured content.
- Management of news, categories and multimedia resources.
- Editing mode for authorized users, with controlled editing of text and images.
- Role and permission system for users, editors, administrators and super administrators.
- Administrator invitations and management through the private dashboard.
- Responsive design for desktop, tablet and mobile devices.
- Custom brand identity with Zirasport editorial components, navigation, header and footer.

### Portal sections

- Men’s football
- Women’s football
- Formula 1
- Argentina national team

### Technologies

- Next.js 16 with the App Router and React Server Components.
- TypeScript with strict typing.
- Tailwind CSS for the responsive visual system.
- PostgreSQL as the database.
- Prisma ORM for data access and schema modeling.
- NextAuth for authentication and sessions.
- Cloudinary for image and video storage and management.
- An architecture based on Server Actions, protected routes and SEO-focused rendering.

### Data model and administration

The platform organizes users, administrator profiles, permissions, invitations, categories, posts, layouts, site content, media assets and audit logs. This makes it possible to expand the portal without relying on a rigid structure while keeping clear control over who can publish or modify each resource.

### Project audience

Zirasport is a freelance project created for a sports brand, digital publication or organization that needs to publish content with its own identity and manage its portal through a private dashboard. The system is designed for small and medium-sized editorial teams that need autonomy to create news, manage multimedia content and keep their sections updated without depending on frequent code changes.

### Goal

To build a scalable, fast and easy-to-manage sports platform with a professional editorial presentation and a solid foundation for adding new categories, authors, formats and features.
